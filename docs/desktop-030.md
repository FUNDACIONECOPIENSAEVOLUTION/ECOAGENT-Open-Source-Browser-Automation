# ECOAGENT 0.30.0
Adds optional local manual takeover of demo/static draft sessions. MCP requests takeover; local capability UI accepts or releases. AI exclusive actions and image tools are blocked during human control. Local UI exposes masked screenshot, inspected element actions, reload/history and limited drafting. No coordinate mouse, arbitrary keyboard, authenticated sessions, dynamic site submission or external upload. Local manual UI still requires end-to-end acceptance; unit tests cover mode exclusion. Existing session expiry can close an idle browser; release remains available locally. Local installation and discovery not changed.
