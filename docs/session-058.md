# 0.58.0 — session and attachment diagnostics

Idle browser retention increases from five to ten minutes; maximum pool size unchanged. Existing approval deadline checks and human handoff remain in place. Batch attachment selection and browser digest failures now return distinct fixed diagnostic codes. Uncertain mutation still closes the affected session; no automatic retry, no raw error detail, no external upload. This narrows the remote failure stage, not a claim that the remote failure is solved. Windows acceptance pending.
