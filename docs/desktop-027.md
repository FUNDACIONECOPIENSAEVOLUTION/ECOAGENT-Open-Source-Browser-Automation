# ECOAGENT 0.27.0
Human-selected documents can be copied into temporary memory using the opt-in loopback UI. PDF, DOCX, XLSX, PPTX, TXT, PNG and JPEG, up to 25 MiB each, four files and 50 MiB aggregate, 15-minute expiry (lazy cleanup). Metadata only over MCP. Files are not interpreted or uploaded to institutions; file extension checks are not malware scanning or format validation. No remote local-file path or content API. Human can remove selected documents. UI capability URL stays in local diagnostics. Tests cover byte integrity, capacity, expiration and a 20 MiB document; live UI upload and external site attachment still need acceptance. New tools require discovery and installation.
