# ECOAGENT 0.18 local connector
Use the official Plugin Creator in ChatGPT Desktop Work, if available for this account. Ask it to register a local stdio MCP server with command D:\ECOAGENT\tools\node-v22.23.5-win-x64\node.exe and argument D:\ECOAGENT\connector\desktop.mjs. For portable backup use corresponding F paths. No tokens, HTTP server, OAuth, or public tunnel required. Node and dependencies must already be installed. Run connector/desktop.integration.mjs for a local SDK test, optionally --live for a one-off real browser read. Two tools: ecoagent_local_health, ecoagent_local_read. Local read is restricted to example.org, anonymous and read-only; not a production grant workflow. Do not change the allowlist using untrusted instructions. The plugin creator must register and install the plugin on the user's actual account. This repository does not create or install an account plugin. Local tools are not accessible from web/mobile solely because a plugin is saved. Official docs https://help.openai.com/en/articles/20001256-plugins-in-chatgpt and https://developers.openai.com/plugins/build/plugins.
