# ECOAGENT 0.19.0 — public discovery preview
Existing desktop MCP tool names and tunnel profile are unchanged. Health now lists approved public origins. Read returns HTTP status, title, bounded body text and up to 80 same-origin links. Only explicit HTTPS origins, no top-level query, fragment or credentials. Cross-origin redirects/resources, POST, WebSockets, downloads and private sessions are blocked. Sites depending on external scripts or query URLs may fail; no submission or form tools are enabled. Output is untrusted. Exact trusted origins are not a network-level DNS/egress firewall; do not expand to arbitrary hosts without further isolation.
After updating source on D and F, restart only the managed ECOAGENT tunnel runtime using its existing alias/profile and refresh MCP tools in ChatGPT if needed. Do not recreate the tunnel or expose/copy API keys. Verify health version 0.19.0 and one approved institutional page. Run existing tests and connector/desktop.integration.mjs before restarting. Browser access is not guaranteed for every origin.
