# ECOAGENT 0.23.0 — offline form review and visual evidence
Adds live_review, live_verify and live_capture. All three are restricted to the synthetic offline fixture, not real institutional forms. Review returns completion/validity flags, verify compares an expected synthetic value without returning stored values, capture returns MCP image content and SHA-256. Never enter real personal data in the fixture. CI now installs Chromium and exercises actual fill, select, verification, review and image return over MCP. Linux CI is not a substitute for Windows acceptance or remote tool discovery. Existing tunnel and updater are unchanged. No real-site submission, uploads, authenticated browser or human takeover in this version.
