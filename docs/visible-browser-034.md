Opt-in ECOAGENT_VISIBLE_BROWSER=1 launches actual Chromium windows instead of headless for temporary live sessions. Existing sandbox and request policies remain. Native window user input can occur independently of MCP; use the local takeover/release panel before interacting and do not type secrets in demo/static mode.
