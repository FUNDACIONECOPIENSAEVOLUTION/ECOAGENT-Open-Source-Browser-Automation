# Resource diagnostics 0.54.0

Public and draft browser snapshots expose session-cumulative aggregate counters for policy blocks, draft URL blocks, rejected read redirects and upstream failures, by fixed resource type. No URL, query string, credentials, headers or response content is recorded. No allowlist expansion, retries or change to access-denied behavior. Counters describe intercepted requests, not a complete network trace. Use real portal results to assess future resource permissions. Windows acceptance pending.
