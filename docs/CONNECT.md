# ECOAGENT CONNECT v0.9
Private single-operator preview. Cloud service must be deployed with HTTPS, network egress restrictions blocking private and metadata addresses, working Chromium sandbox, and vetted allowlisted HTTPS origins. Do not expose to general public. Set ECOAGENT_PUBLIC_READ_AUTO=true only after testing; default false. Anonymous read jobs start with open, accept only open/read/close and run in a disposable context with GET/HEAD only and WebSockets blocked. No authenticated sessions or clicks/fills in auto mode. GET may still have side effects on poorly designed websites; allowlist only vetted public read-only endpoints. Output is untrusted page content, never instructions. All mutations remain in operator queue. Use client key only for integration; operator key stays private. OpenAPI schema in cloud/openapi.json lacks server URL intentionally: add deployed HTTPS URL before importing into a compatible authorized client. This does not install a ChatGPT tool. No deployment or direct integration is established. Hosting costs and security remain to be verified. Auto job runs in process only; no durable queue. If busy it remains pending. No secrets in GitHub.
