# HTTPS gateway 0.15 (private preview)
Gateway binds only 127.0.0.1:8082 and forwards only POST /mcp and GET protected resource metadata to connector 8081. It refuses startup unless OAuth metadata matches the configured public HTTPS resource. No route to local browser, extension or REST backend. It does not provide TLS or an authorization server itself. Configure external OAuth provider and connector first (GATEWAY.md). Cloudflare named tunnel: choose a hostname in a domain under your control, map only that hostname to http://127.0.0.1:8082 and use a catch-all 404. Use Cloudflare's official Windows connector installation instructions, keep tunnel credentials private. Set rate limiting at edge, validate OAuth end-to-end, restrict identities at provider, and implement network egress protections for browser before allowing actual remote reading. Never tunnel 8790, 8791, 8080, or 8081 directly. No tunnel or provider has been created; no hosting costs approved. Local unified preview stays unchanged. No unauthenticated public browsing. ChatGPT custom MCP support depends on plan and permissions; register once in Plugins > Add custom MCP server if available, choose OAuth, use actual HTTPS hostname + /mcp. No fabricated hostname. Official docs: https://developers.cloudflare.com/tunnel/get-started/ and https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt.
