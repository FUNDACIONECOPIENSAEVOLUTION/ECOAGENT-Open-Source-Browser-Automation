# Actionable link search 0.53.0

Locate returns a fresh snapshot plus actionable same-origin navigation links, including links outside the viewport. Up to 1000 anchors scanned and 40 references returned. Non-link matches remain informational. Search invalidates prior snapshot references; callers must use the returned snapshot and ID. Follow revalidates the live anchor and rejects downloads. No new origins or write privileges. External acceptance pending.
