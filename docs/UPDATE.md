# Version 0.16 — pinned updater and OAuth preflight
Use actualizar-ecoagent.ps1 -Commit <trusted exact commit SHA>. Stop ECOAGENT first. Downloads only allowlisted tracked source paths, verifies Git blob hashes against the pinned GitHub tree, stages before copying to D and F, and does not delete old source files or touch node_modules, local profiles, or secrets. Not a signed installer; trust the repository/commit. Copy is not transactional across drives, and interruption may leave a partial update; rerun the same commit. Dependencies must be updated separately when package.json changes. Does not install or start anything. Existing custom source changes may be overwritten. Gateway config.example.json is an example only, no real credentials. check-config.mjs validates OAuth discovery metadata for compatible providers, not actual login or token introspection. No Cloudflare or OAuth account access available in this conversation; no tunnel created. Do not publish until deployment gates are met.
