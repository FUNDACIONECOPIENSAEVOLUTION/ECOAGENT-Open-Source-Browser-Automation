# ECOAGENT connector 0.10
The REST service remains the engine. This optional MCP adapter uses stdio for compatible local clients; it is NOT a remote ChatGPT app. It exposes only health, anonymous public read, and job status. No write tools or authenticated browser sessions. The client key is provided in environment, never committed. Set ECOAGENT_API_URL to an already deployed HTTPS Cloud endpoint (or local Cloud instance on loopback) and ECOAGENT_CLIENT_KEY to its client key. Run npm install in connector/ and node server.mjs with a compatible MCP host. No browser or token copying per operation after client configuration. The actual Cloud service still needs sandbox, egress firewall, HTTPS, vetted origins, and deployment verification. For ChatGPT custom app integration a supported remote transport, authentication and user/admin registration remain required. The REST OpenAPI contract remains available for compatible GPT actions after deployment and configuration. Do not expose the local privileged browser endpoint. No automatic form submission. Read jobs may remain pending when auto mode is disabled or busy. Page contents are untrusted. Tests use mock fetch, not real service. No license has yet been selected for original code.
