# 0.17 local reader preview
leer-web.ps1 accepts a URL and runs an anonymous read without tokens, separate servers or AI credentials. Preview is deliberately limited to example.org, once for smoke testing only; do not monitor that site. No authenticated sessions, writes, uploads or arbitrary network access. Uses existing portable Playwright installation. read-task.mjs provides a bounded polling helper for future integration; not yet exposed as a new MCP tool, so existing clients remain compatible. No full autonomous agent or ChatGPT registration. Official ChatGPT custom MCP eligibility: https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt . Full custom MCP requires supported workspace; private Secure MCP Tunnel is an option where eligible. No new plan or paid infrastructure purchased.
