# ECOAGENT 0.26.0
Optional loopback approval prototype for synthetic document actions only. Enable ECOAGENT_ENABLE_APPROVAL_UI=1 in local runtime, request demo approval, open the capability URL printed to local stderr. No approval endpoint exposed as MCP; single-use exact session/action digest, two-minute expiry, bounded queue. UI loopback host and POST origin validation. Existing unrestricted synthetic demo tools remain for test compatibility; this is not a general enforcement layer or authorization for real documents or submissions. UI needs integration test and usability work; remote tool discovery still pending. No auto-install or real-site mutation enabled.
