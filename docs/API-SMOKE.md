# Prueba integral local por API
Requiere Node 22, Playwright y Chromium previamente instalados. Desde la raíz: node scripts/api-smoke.mjs. La variable PLAYWRIGHT_BROWSERS_PATH debe apuntar al directorio de los binarios instalados. Inicia un servidor de formulario sintético en loopback y un motor ECOAGENT en puerto temporal, con perfil de prueba separado. Comprueba autenticación, bloqueo del modo privado, apertura, inspección, campos, selección, clic, resultado y captura. No envía datos a terceros ni usa sesiones reales. Elimina el perfil temporal al terminar. La prueba no acredita despliegue Cloud, integración ChatGPT ni compatibilidad universal. Pendiente ejecutar en Windows.
