# Instalación D y F
Descargue y revise instalar-d-f.ps1 del repositorio antes de ejecutarlo. Desde PowerShell: powershell -ExecutionPolicy Bypass -File .\instalar-d-f.ps1. No requiere administrador. Comprueba ambos discos, descarga ZIP oficial una sola vez, copia código a D:\ECOAGENT y F:\ECOAGENT, no copia perfiles ni datos privados. Si detecta .git, no sobrescribe; actualice esos repositorios por separado con git pull --ff-only. En carpetas ZIP existentes actualiza archivos del repositorio sin borrar otros; respalde cambios locales antes. Node.js 22+ requerido para puente; no se instala automáticamente. F es respaldo del código, no de las sesiones. Cargar extensión desde D:\ECOAGENT\extension en chrome://extensions. Ejecutar iniciar-bridge.ps1. El portal público GitHub Pages no controla el navegador local ni ofrece visualización en vivo. El panel local alternativo usa puerto 8790 y requiere instalar Playwright mediante instalar.ps1. El puente Chrome usa 8791 y no requiere dependencias npm. No exponer puertos a internet. Pruebas Windows pendientes.
