# Live View local
Visor experimental de capturas JPEG periódicas (aprox. 1.8 segundos más latencia), no streaming de vídeo. GET /api/v1/live exige el token del motor y solo está disponible en loopback. No crea archivos de captura por cada cuadro. Se desactiva desde el panel al activar modo privado o cambiar perfil y el servidor rechaza capturas en modo privado o ante campos de autenticación conocidos en frames. El filtro es heurístico; no habilitar en páginas confidenciales. Las capturas pueden contener información privada. No se transmiten a ChatGPT. El panel permite navegación, desplazamiento, inspección y acciones por elementos, no clic por coordenadas. El motor dedicado no usa el perfil habitual; la extensión sigue siendo alternativa. Pendiente prueba real en Windows. El puerto no debe exponerse a internet.
