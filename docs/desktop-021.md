# ECOAGENT 0.21.0 — temporary public navigation sessions
Adds open, inspect, follow and close MCP tools. Four in-memory sessions maximum, ten-minute idle expiry; opaque random IDs and fresh snapshot references; follow accepts only validated same-origin links returned by the current page. Each navigation uses a new isolated Chromium process, not a persistent browser, cookie jar or login session. No arbitrary selectors, form submission, credentials, uploads or writes. Public webpage content is untrusted. Session IDs are bearer capabilities within the single-user private runtime; do not expose them publicly. Existing read and discovery tools remain. On installation restart the existing tunnel and refresh tool discovery; verify health and open/inspect/follow/close with approved public pages. No automatic release is published; updater pilot remains unchanged.
