# Browser integration preview 0.13
Run connector/browser.integration.mjs with Node 22 after installing dependencies in root and connector and Playwright Chromium. Test creates two temporary loopback services, random per-test keys, and an isolated anonymous browser. Only example.org is allowed. Auto read is enabled solely for these test processes. It checks real MCP HTTP transport, REST job submission, live browser page title/text and unauthorized rejection. Requires internet and working Chromium sandbox; never disable sandbox to make test pass. Not a deployment or ChatGPT registration. Existing unified launcher now hides local and bridge tokens in logs; for manual access stop unified and use standalone launcher (or standalone bridge). This trades convenient manual panel access for less accidental log disclosure; future secure local credential provisioning needed. No public endpoint, OAuth or automatic writes added.
