# ECOAGENT 0.29.0
Adds active-tab reload and browser history back/forward with fresh element references. Detects modified static draft inputs, selects, checkboxes and file inputs before reload/history; returns unsaved_draft without closing or refreshing. Explicit discard parameter is for user-authorized loss of changes, not an independent approval UI. The guard is limited to static draft/demo and does not guarantee recovery of dynamic application state. Existing same-origin read-only routing remains. Tests exercise blocked reload, retained value, explicit reload and history traversal in the offline fixture. No external submission. Local installation and ChatGPT tool discovery still pending.
