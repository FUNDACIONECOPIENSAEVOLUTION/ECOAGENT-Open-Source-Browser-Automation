# ECOAGENT 0.33.0 document generation prototype

Adds one MCP tool for generating bounded plain-text PDF, DOCX and XLSX into the existing temporary vault. XLSX cells are literal text, not formulas. PDF has basic pagination and Latin-1 limits. No external submission, arbitrary paths, macros or signatures. Existing local attachment approval remains unchanged. No claim of real portal compatibility until separate testing. CI and Windows installation pending.
