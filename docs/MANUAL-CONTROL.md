# Control humano local v0.8
El operador puede tomar control desde el panel autenticado. Mientras está activo, el servidor rechaza lotes de automatización excepto consulta de estado y entrada a modo privado. El visor devuelve una referencia de captura efímera, requerida para clic, desplazamiento y escritura. No permite acciones sobre una captura vieja o de otra página. Las referencias no garantizan que el DOM no haya cambiado dinámicamente; verifique antes de hacer clic. La escritura usa un campo explícito, no captura global de teclado. El modo privado desactiva control por visor; use la ventana real para autenticación, contraseñas, CAPTCHA y operaciones no compatibles. El filtro de campos sensibles es heurístico. No comparta el token ni exponga el puerto. El bloqueo es de cooperación entre clientes autenticados, no protección contra un cliente malicioso que posee el token completo. El mismo navegador y sesión se mantienen al ceder el control. Pendiente prueba real en Windows. No incluye todavía control desde ChatGPT ni despliegue Cloud.
