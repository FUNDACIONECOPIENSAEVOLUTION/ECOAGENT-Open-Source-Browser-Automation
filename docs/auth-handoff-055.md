# Authentication handoff 0.55.0

Manual takeover reports whether a native authentication permit was prepared, and the local panel directs the human to the visible browser rather than requesting an unavailable preview. Blocked inspection no longer attempts to iterate missing elements. A premature release while the authentication screen remains does not revoke the existing unexpired one-shot permit. No renewal, credential collection, automated authentication, external SSO or CAPTCHA bypass. Real login acceptance remains pending.
