# ECOAGENT 0.20.0 — public discovery batches
Adds ecoagent_discover (1–5 approved public URLs, sequential isolated reads). Validates the whole batch before navigation, deduplicates, bounds returned text/links/fields, stops on HTTP 429 or browser failure. A 403 is not a successful page read. No write, form submission, login or upload tool. The maximum runtime can exceed a single client MCP timeout; use one or two URLs initially, and do not retry rate limits automatically. Existing health/read names and tunnel identity are preserved. After local installation and runtime restart refresh the custom MCP server tool discovery if needed. The automatic updater remains the 0.19.1 pilot; do not enable unattended updates until Windows rollback and idle coordination are validated. No stable release is published by this commit.
