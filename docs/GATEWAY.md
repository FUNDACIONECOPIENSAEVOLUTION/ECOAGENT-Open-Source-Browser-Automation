# Secure Gateway 0.14 — resource server preview
Default local Bearer mode remains unchanged. Optional ECOAGENT_AUTH_MODE=oauth activates protected resource metadata and external token introspection, not an authorization server. Configure ECOAGENT_RESOURCE_URL=https://your-host/mcp, ECOAGENT_OAUTH_ISSUER (exact issuer returned by introspection, normalized URL), ECOAGENT_INTROSPECTION_URL, ECOAGENT_INTROSPECTION_ID, ECOAGENT_INTROSPECTION_SECRET. Keep all secrets out of GitHub. Provider must support OAuth authorization code + PKCE, ChatGPT client registration/metadata and callbacks, resource indicators, scope ecoagent.read, and introspection returning active, iss, aud, exp, scope. The resource server denies mismatches and failures. No local static key fallback in OAuth mode. Configure a trusted HTTPS reverse proxy with rate limits before exposure; do not expose 8790, 8791 or 8080. External provider, actual TLS endpoint, OAuth end-to-end and ChatGPT registration are not yet configured. Use official docs https://developers.openai.com/plugins/build/auth and https://developers.openai.com/api/docs/guides/custom-mcp-server. Tools are limited to public anonymous reading and status. Read-only annotations describe external effect; job creation has internal state. No authenticated browsing or automatic submissions. Plan/workspace permissions may limit custom tools. Never bypass platform confirmations.
