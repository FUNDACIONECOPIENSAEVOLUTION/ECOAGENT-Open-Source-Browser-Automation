# Local document preparation 0.55.0

Preparing documents now opens the dedicated visible loopback panel directly; its capability URL is never returned to MCP. Human file selection remains mandatory. No upload or approval occurs by opening the panel. Synthetic approval instructions reference the existing panel tool rather than removed diagnostic output. Closed panel contexts are disposed before recreating the page. Same-origin capability URL restrictions remain unchanged. End-to-end original PDF/DOCX transfer and Windows UI acceptance remain pending.
