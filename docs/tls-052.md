# Windows TLS and maintenance 0.52.0

Managed Windows launch commands opt into Node 22.19+ --use-system-ca, adding the existing Windows trusted roots to bundled CAs. No certificates are imported and TLS verification remains required. Trust in the existing OS store is a prerequisite. Fixed diagnostic labels distinguish expired certificates, hostname mismatches and untrusted chains. Installer waits up to 30 seconds for existing desktop processes to exit; it never kills residual processes. Initial installation uses the previously approved installer unless the new script is explicitly downloaded and verified. Real Grants.gov access and Windows acceptance are pending.

Reference: https://nodejs.org/download/release/v22.23.0/docs/api/cli.html
