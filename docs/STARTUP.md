# Arranque integrado Windows
Desde D:\ECOAGENT ejecute arrancar-ecoagent.ps1. Detecta Node portable y conserva dependencias en la carpeta. El servidor local se mantiene en 127.0.0.1:8790. La opción -NoBrowser evita abrir el panel. Opcional: registrar-arranque.ps1 registra una tarea de Windows bajo la cuenta interactiva actual, sin privilegios elevados; puede requerir permisos del sistema. Para retirar: Unregister-ScheduledTask -TaskName 'ECOAGENT Local' -Confirm:$false. No inicia al estar apagado ni instala integración ChatGPT. El token temporal sigue siendo necesario en el panel local. No abrir puertos del router.
