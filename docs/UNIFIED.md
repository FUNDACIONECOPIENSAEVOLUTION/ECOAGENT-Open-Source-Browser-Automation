# Unified preview 0.12
Start arrancar-unificado.ps1 from either portable drive after stopping old services. Four children share one supervisor; all listeners bind to loopback. Cloud and connector keys are random per run and kept in memory/environment, not GitHub or disk. Existing local and bridge services still print their own temporary tokens. Auto read disabled by default. Cloud/connector health checked, not actual browser navigation. Fail-fast on port collision or child exit; no automatic restart yet. Ctrl+C requests child shutdown (browser child cleanup on Windows must be verified). HTTP integration exercises actual MCP transport with a mock backend; not live browser or ChatGPT. No public exposure. Existing cloud deployment configuration may need explicit ECOAGENT_CLOUD_BIND=0.0.0.0 behind protected infrastructure. Do not enable until deployment gates satisfied.
