Instalación Windows · modo extensión histórico

Para el conector nativo consulta primero el estado MCP y el procedimiento de mantenimiento; no ejecutes instaladores antiguos como sustituto de una actualización verificada.

  1. Descarga y revisa instalar-d-f.ps1.
  2. Ejecuta el script desde PowerShell con Node.js y Git disponibles, o usa la descarga ZIP automática.
  3. En chrome://extensions activa modo desarrollador y carga D:\ECOAGENT\extension.
  4. Ejecuta D:\ECOAGENT\iniciar-bridge.ps1 y utiliza la clave OPERADOR únicamente en la extensión.
